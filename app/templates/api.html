How it works

Send a plant name and a destination. The API reports whether that species has a regulation record in that jurisdiction, so you can flag products for review before they are sold or shipped.

It is deliberately conservative: it does not say a plant is legal or banned. If a name is ambiguous or badly misspelled, it returns suggestions to choose from instead of guessing. 

POST /v1/regulatory-check
{
  "plant_query": "Cortaderia jubata",
  "ship_to": { "country": "US", "region": "CA" }
}

What you get

  • Fewer restricted sales. Flag regulated plants before checkout, catalogue approval or shipment.
  • Real-world plant names. Scientific names, common names, synonyms and near-spellings all match.
  • Evidence with every answer. The regulating authority, its classification and notes, and the data release used.
